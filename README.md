# Rock Paper Scissors

A simple Rock Paper Scissors game built with JavaScript as part of [The Odin Project – Foundations](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

## About

This is a browser-based Rock Paper Scissors game where you play against the computer. The game runs entirely in the browser console and uses prompts to collect the player's choices.

## Features

- Player input using browser prompts.
- Random computer choices using `Math.random()`.
- Round results for wins, losses, and draws.
- Human and computer score tracking.
- A final scorecard displayed in the console.

## Built With

- HTML
- JavaScript

## How to Play

1. Clone this repository:
   ```bash
   git clone https://github.com/NeuronEdge67/Odin-project-rock-paper-scissors.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Follow the browser prompts and enter `rock`, `paper`, or `scissors`.
5. Open the browser developer console (`F12`) to see the results and scores.
